# Privacy Policy

FlowFlox Tools receives a FlowFlox signed service key only through the
**Connect FlowFlox** node inside a Dify app. It exchanges that key for a
narrow app capability and sends the capability to the FlowFlox API gateway to
list APIs granted to that app and call an explicitly selected operation.

The plugin never persists or returns the signed service key. It stores only
the app capability under the Dify app ID, and does not persist user prompts,
tool arguments, or tool responses. FlowFlox records only the aggregate API
usage required for its catalogue audit trail. FlowFlox never exposes raw
database, storage, cloud, or provider credentials through this integration.

For privacy questions, contact the FlowFlox platform administrator.
