# Privacy Policy

FlowFlox Tools receives one FlowFlox signed service key in Dify's encrypted
credential store. The plugin sends that key only to the FlowFlox API tools
gateway to list APIs granted to the key and to call an explicitly selected
operation.

The plugin does not persist the key, user prompts, tool arguments, or tool
responses. FlowFlox records only the aggregate API usage required for its
catalogue audit trail. FlowFlox never exposes raw database, storage, cloud, or
provider credentials through this integration.

For privacy questions, contact the FlowFlox platform administrator.
