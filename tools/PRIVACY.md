# Privacy Policy

FlowFlox Tools receives a short-lived, single-use Dify authorization code only
through the **Authorize FlowFlox app** setup node inside a saved Dify app. It
exchanges that code for a narrow app capability and sends the capability to
the FlowFlox API gateway to list APIs granted to that app and call an
explicitly selected operation.

The plugin never receives, persists, or returns a durable FlowFlox service
key. It stores only the app capability under the Dify app ID, and does not
persist user prompts, tool arguments, or tool responses. FlowFlox records only
the aggregate API usage required for its catalogue audit trail. FlowFlox never
exposes raw database, storage, cloud, or provider credentials through this
integration.

For privacy questions, contact the FlowFlox platform administrator.
